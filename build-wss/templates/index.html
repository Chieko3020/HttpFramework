HttpFramework 综合测试服务器

API接口

GET /api/status
获取服务器状态信息
GET /api/time
获取当前服务器时间
POST /api/echo
回显POST数据 (使用curl测试)

会话管理

GET /session/info
查看当前会话信息
GET /session/stats
会话统计信息
POST /session/set
设置会话数据 (使用curl测试)

数据库功能

GET /db/test
测试数据库连接
GET /db/users
查看所有用户
GET /db/add-user
添加用户表单

系统信息

HTTP服务器: http://localhost:8080

数据库: MySQL (httpframework)

会话管理: 已启用 (30分钟过期)

连接池: 5 个连接

快速测试

点击上面的链接测试各个功能，或者使用curl命令：

# 测试API
curl http://localhost:8080/api/status
curl http://localhost:8080/api/time

# 测试会话
curl http://localhost:8080/session/info

# 测试数据库
curl http://localhost:8080/db/test
curl http://localhost:8080/db/users

# 测试POST请求
curl -X POST http://localhost:8080/api/echo -d "Hello World"
